#+title: Org Dispatch

=C-c m= dispatches the full top-level subtree containing point, including when
point is inside a child heading. Reusable prompts are ordinary static headings;
TODO is optional. Yasnippet remains a separate writing aid.

* Usage

=-m= model, =-d= workspace directory, =-A= CLI arguments, =-o= output.
=v= previews; =C-c C-c= copies the frozen preview; =q= closes it.
=w= copies directly; =RET= invokes the selected output (clipboard by default).
Overrides last for one menu invocation and never modify the source.

#+begin_src org
,* Review Org-roam graph
:PROPERTIES:
:DIRECTORY: ~/notes/work/roam/
:END:
Review missing connections and duplicate concepts in this graph.

,* TODO Review token expiry
:PROPERTIES:
:DIRECTORY: ~/.workspaces/token-expiry/
:MODEL: your-model
:CLI_ARGS: --flag "two words"
:END:
Review API and frontend expiry handling.
,** Requirements
Explain inconsistencies with evidence.
#+end_src

MODEL, DIRECTORY, and CLI_ARGS are read from the top-level heading, with Org
file-property defaults supported. Child properties do not override the unit.
Absent values use =org-dispatch-default-model=, =org-dispatch-default-directory=,
and =org-dispatch-default-arguments=. An unset directory uses the source buffer's
directory. Relative paths resolve there. Model metadata is optional and does
not select a model in the application receiving clipboard text.

Copied text begins with =Workspace: /path/=, followed by the cleaned subtree.
Links, blocks, and heading structure remain; drawers, planning dates, TODO
keywords, priorities, and tags are omitted. No links or code are evaluated.

* Templates

In Org, type =task= or =prompt= and press =TAB= to insert a heading template.
Use Insert state with Evil. =C-c & C-s= also selects a snippet by name.
Fill fields with =TAB=; =S-TAB= goes back. Leave model blank to use the default.
Then =C-c m=, =RET= copies the unit. Expansion writes ordinary Org text;
dispatch never expands templates.

Edit templates under =~/.config/home-manager/.emacs.d/snippets/org-mode/= and run
=M-x yas-reload-all= after changing them.

* Adapters

=org-dispatch-data= returns a plist: =:title=, =:text=, =:directory=,
=:arguments= (a list of strings), and =:model= only when specified.
CLI arguments use double quotes to group words; they are never executed here.

An output accepts that plist and signals on failure:

#+begin_src emacs-lisp
(setf (alist-get 'my-output org-dispatch-outputs) #'my-dispatch-function)
#+end_src

Select it with =-o= and invoke it with =RET=. Clipboard is the only built-in
output. Terminal/CLI integration can live in a separate adapter.
